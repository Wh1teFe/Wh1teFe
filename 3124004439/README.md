## Project Description
This is a personal assignment for Software Engineering.
The program uses the SimHash algorithm to calculate the similarity between two text files and output the plagiarism rate.

### File Structure
- simhash.h: header file
- simhash.cpp: implementation of simhash functions
- main.cpp: program entry, read two texts and output similarity
- unit_test.cpp: unit test code

### How to Run

main.exe orig.txt copy.txt ans.txt

The result will be saved into ans.txt.
